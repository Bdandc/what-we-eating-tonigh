# WAWET — What Are We Eating Tonight?

One dinner suggestion a day, nothing else. Shuffle up to 3 times, swap to a kids
suggestion, mark takeaway day, and tell it what's in the pantry so suggestions
stay realistic.

- Product + technical spec: [redesign-plan.md](./redesign-plan.md) (consensus-reviewed by Kimi K3 + Codex, 2026-07-30)
- Design source: Figma "BD&C Brand" frame `2660:8423` (5 mobile screens)
- Local-first: all state in `localStorage` (`wawet-state-v1`); no backend, no accounts
- Stack: Next.js 16 (App Router) + React 19 + Tailwind 4, deployed on Vercel
